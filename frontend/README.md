# frontend

Next.js monitoring dashboard. Not yet implemented — the project is still in the
ML research phase (see root [README](../README.md)).

Planned pages once the backend exposes an inference API:

- Fleet dashboard — machine counts by health status, failure risk, active anomalies.
- Machine detail page — status, failure probability, RUL, sensor trend charts.
- Real-time view driven by the WebSocket sensor simulator.
- Maintenance history log.

Target stack: Next.js, TypeScript, Recharts, WebSockets.
